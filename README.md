# TaskFlow

## Prerequisites
- Flutter stable SDK
- Firebase project with Email/Password Authentication and Cloud Firestore enabled
- FlutterFire CLI configured for the project

## Firebase Setup
Add `google-services.json` to `android/app/google-services.json`.

## Run
```bash
flutter pub get
flutter run
```

## APK
Signed release APK: `build/app/outputs/flutter-apk/app-release.apk`
